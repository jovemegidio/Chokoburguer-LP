CHOKE BURGUER - BASE HTML/CSS/JS

Arquivos principais:
- index.html
- style.css
- script.js
- pasta /assets

Como editar:
1. Troque o número do WhatsApp no arquivo script.js em WHATSAPP_NUMBER.
2. Edite os itens do cardápio no array menuItems no script.js.
3. Troque horários, endereço e Instagram no index.html.
4. Substitua as imagens da pasta /assets mantendo os mesmos nomes, se quiser.

Funcionalidades incluídas:
- Menu mobile
- Filtro por categoria
- Busca por item
- Cards renderizados via JavaScript
- Modal de visualização do item
- Botão de pedido por WhatsApp com mensagem automática
- Scrollspy no menu
- Animação de entrada ao rolar a página
